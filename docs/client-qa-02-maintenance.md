# tayumano AIチャットBot — 保守運用コスト試算

作成日: 2026-03-13

---

## 前提

- 弊社はITベンダー／MSP（マネージドサービスプロバイダー）ではない
- 専任のインフラエンジニア・SREは不在
- 本業の傍らで対応する想定のため、稼働時間は限定的
- 構成は Cloudflare Workers + Pages + Gemini API（有料枠）を想定

---

### 弊社運用のリスク

| リスク | 内容 | 影響度 |
|---|---|---|
| 属人化 | 担当者が1人の場合、休暇・退職時に対応不能 | 高 |
| 本業圧迫 | 障害対応が本業の繁忙期と重なる可能性 | 中 |
| 責任範囲の曖昧さ | 「ボットが変な回答をした」等のクレーム対応を誰がするか | 中 |
| APIモデル廃止 | Googleがモデルを廃止した場合の緊急対応（今回のgemini-2.0-proのように） | 中 |
| コスト立替 | API費用を弊社が立て替え → クライアントに請求する運用フローが必要 | 低 |

### 弊社運用の場合に最低限やるべきこと

1. Google AI Studio の月額予算アラート設定（¥10,000 / ¥50,000 の2段階）
2. Cloudflare のエラー通知をメールまたはSlackに飛ばす設定
3. 月1回の利用状況レポート（会話数・API費用）をクライアントに共有
4. 保守契約書で責任範囲（SLA / 対応時間 / 免責事項）を明確にする

## 推奨

| 条件 | 推奨パターン | 理由 |
|---|---|---|
| キャンペーン期間が短い（1〜3ヶ月） | **A: 弊社運用** | 引き渡しコストをかけるより弊社で回す方が安い |
| 長期運用（半年以上） | **B: クライアント引き渡し** | 月額の人件費が積み上がるより初期投資で渡した方がトータル安い |
| クライアントにIT担当者がいない | **A: 弊社運用** | 引き渡しても運用できない可能性が高い |
| クライアントにIT担当者がいる | **B: クライアント引き渡し** | スポット保守のみで自走できる |

### 損益分岐の目安（標準シナリオ）

- パターンA: 月額¥25,900 × 継続
- パターンB: 初期¥300,000 + 月額¥11,000（実費 + スポット月割）

→ **パターンBの初期投資は約20ヶ月で回収。** ただしキャンペーン用途なら期間が短いためパターンAが合理的。
