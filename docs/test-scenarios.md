- **入力**: 「夜遅いし、カフェインは控えたい」

- **前提**: MOCK_CHAT=true は SalesRule キーワードマッチのみ。Gemini（MOCK_CHAT=false）では product.scenes=["朝"] / product.moods=["シャキッと"] を使って静かなる覚醒の煎茶を推薦するはず（未検証）
